# App utilities and reusable logic

This is the reuse index for non-component logic in `packages/app`. Check here before adding a helper, selector, hook, or store primitive. The component catalog is in [COMPONENTS.md](./COMPONENTS.md).

## Reuse rules

1. Put stateless helpers in `src/app/utils/`; keep them independent of React unless the file is explicitly a hook.
2. Put entity selectors and subscriptions in `src/app/hooks/`; use hooks in render and `getX()` getters only in actions/non-reactive code.
3. Put shared state primitives in `src/app/hooks/store/`; entity mutations still belong in `src/app/store/actions/`.
4. Keep API transport in `src/app/api/` and mutations in `src/app/store/actions/`. Neither layer is a utility substitute.
5. Reuse the existing date, duration, color, URL, storage, and sanitization helpers rather than adding local variants.
6. New pure logic in `utils/` or `hooks/` needs a focused unit test.

## Fast selection guide

| Need                                       | Use first                                                                      | Notes                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Format or parse a date                     | `utils/date`                                                                   | Uses date-fns and the app's locale setup.                                 |
| Convert seconds to human duration          | `utils/date` (`formatStringDuration`, `formatDuration`, `parseStringDuration`) | Time logs and API-style seconds.                                          |
| Parse legacy `2w 4d 6h` plan syntax        | `utils/string` (`timeToMinutes`, `minutesToTime`, `parseTime`)                 | Separate from the seconds-based helpers in `utils/date`.                  |
| Time-zone-safe calendar day key            | `utils/date/toCalendarDateKey`                                                 | Use for date-only comparisons and filter ranges.                          |
| Resolve named date filters                 | `utils/date/getNamedDateFilterRange`                                           | Returns inclusive `yyyy-MM-dd` bounds.                                    |
| Derive a stable color from a string        | `utils/colors` (`stringToColour`, `stringToHsl`)                               | Existing deterministic palette helpers.                                   |
| Choose readable text on a background       | `utils/colors` (`getTextColor`, `isLight`)                                     | Avoid reimplementing contrast math.                                       |
| Reorder a persisted ID list                | `utils/array/reorderWithAfter` or `utils/taskOrder/sortByIdOrder`              | `reorderWithAfter` reports the predecessor; `sortByIdOrder` sorts a copy. |
| Flatten or inspect a tree                  | `utils/array` (`flattenTree`, `getParentAtIndex`)                              | Generic tree helpers.                                                     |
| Serialize/parse project filters in the URL | `utils/filterQueryParams`                                                      | Includes shareable-state and drawer-open logic.                           |
| Filter workbook task trees                 | `utils/workbookTasks`                                                          | Preserves ancestors/descendants after strict matching.                    |
| Open links or copy text                    | `utils/browser`                                                                | Rejects unsafe new-tab protocols.                                         |
| Tenant-scoped local storage                | `utils/storage`                                                                | Call `setStorageTenant` from authenticated boot.                          |
| User notifications                         | `utils/toast` or `window.toaster`                                              | Reuse the global Blueprint toaster.                                       |
| Sanitize stored rich HTML                  | `utils/safeHtml`                                                               | Required before injecting trusted-looking stored HTML.                    |
| Generic click/visibility behavior          | `hooks/utils`                                                                  | Existing outside-click and intersection-observer hooks.                   |
| Entity state and equality                  | `hooks/store`                                                                  | `entity`, `useEntity`, equality helpers, persistence/alias plugins.       |
| Derived task lists                         | `hooks/tasks`                                                                  | Existing filters, grouping, dependency, and sort selectors.               |
| Debounce or interval                       | `hooks/timer`                                                                  | Existing hook implementations.                                            |

## Shared store primitives

These live under `packages/app/src/app/hooks/store/`.

| Export                                                                                        | Use when                                                         | Notes                                                                                                     |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |

## Not utilities

Use these layers instead of adding their responsibilities to `utils/` or shared hooks:

- **API transport:** `src/app/api/<domain>.ts` and `src/app/api/request.ts`.
- **Store mutations and side effects:** `src/app/store/actions/<domain>.ts`.
- **Entity slices:** `src/app/store/<domain>.ts`.
- **UI composition:** `src/app/components/` and `src/app/widgets/`; see [COMPONENTS.md](./COMPONENTS.md).
- **Translations:** locale JSON under `packages/server/locales/app/`, managed through `@stacks/locales-tui`.

## Maintenance

When adding reusable logic:

1. Choose `utils/` for pure behavior, `hooks/` for React subscriptions/selectors, or `hooks/store/` for state primitives.
2. Add a focused unit test for new pure logic.
3. Export through the owning barrel where appropriate and add a row to this file.
4. Update [COMPONENTS.md](./COMPONENTS.md) instead if the reusable unit is rendered UI.
5. Run `yarn prettier --write packages/app/UTILS.md` after editing.
