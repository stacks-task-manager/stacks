# REST, MCP and chat authorization evidence

This is the retained operation-to-test map for the finite registries checked on 2026-10-19.
Security test filenames are relative to `packages/server/test/security/`; `src/...` test paths are
relative to `packages/server/`.
REST routes are read from the mounted Hono route table (`app.routes`), excluding the explicitly
public `/api/info` route and framework `HEAD`/`OPTIONS` entries. `ALL` middleware/dispatcher entries
are not counted; the MCP dispatcher is accounted for by the separate tool registry below. The current inventory has **106
unique method/path operations**. `apiRouterAuthentication.test.ts` dynamically creates one unauthenticated
401 case for every registered operation; its separate public-info and unmounted-path cases document
the exclusions. Domain tests below supply applicable authenticated authorization evidence. Rows group operations that
share domain policy; this map is not a claim that every boundary has a separate HTTP test for each
method. Source inspection on 2026-10-20 corrected test paths and classified unimplemented stack routes;
no new runtime suite result is implied by those documentation corrections.
